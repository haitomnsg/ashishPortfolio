05 · Crossroads2024‑12Robotics · AI · Software
TomatoBot v2

An autonomous harvesting robot for tomato farms, later published in IJICTDC. I framed the arm as an inverse‑kinematics problem and the field as a segmentation problem: YOLOv11 tells ripe from unripe at 88% in real fields, a U‑Net finds the row, and a Deep Hough transform turns it into one line to follow.

Decisions

Everything runs on a Raspberry Pi at the edge, so every model was chosen for latency first and accuracy second. The Android app exposes both a manual mode and a fully autonomous one, because a farmer will not trust a robot they cannot override.

05 · Recommendation

Geist Sans + Geist Mono, unless you want warmth.

Why Geist wins

Your README asks for Apple‑like restraint and one strong family that handles both 96 px headlines and dense technical text. Geist does exactly that, and its mono means one download, one rhythm, one voice across placards and prose. With a cyan light and a cute robot already in the room, the type should be the calmest thing on screen.

When to pick Manrope instead

If, when you see Alu modelled, the site feels too cool and clinical, switch to Manrope with JetBrains Mono. Its rounded geometry echoes Alu's body and takes the edge off the navy. It is a one‑line token change, so the decision is reversible until M2.

Rules either way

  • Two weights only: 400 and 500 (600 reserved for one word, if ever).
  • Tracking −2% above 40 px, +8% on mono labels.
  • Navy ink on white, ice‑white ink on navy. Never pure black.
  • No gradient text, no all‑caps headlines, no typewriter effect.
